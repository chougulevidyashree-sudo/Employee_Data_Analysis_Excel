# Employee_Data_Analysis_Excel
Employee Data Project Analysis project in Excel with data cleaning an interactive dashboard
This project is a Customer Dashboard built in Power BI to analyze customer-related data. It provides interactive visualizations and insights into customer demographics, purchase behavior, and overall business performance.

🎯 Key Features
Customer demographics (age, gender, location)

Sales & revenue trends with KPIs

Customer segmentation (high-value vs. low-value)

Retention & churn analysis

Interactive filters and drill-down options

🛠️ Tools & Technologies
Power BI Desktop (.pbix file)

Dataset: Customer transaction data (CSV/Excel)

Data cleaning & transformation using Power Query

Visualizations: charts, KPIs, slicers

🚀 How to Use
Download the .pbix file.

Open it in Power BI Desktop.

Connect to the dataset (or replace with your own).

Explore the dashboard with filters and drill-downs.

📊 Employee Data Analysis – Excel Project
🔎 Overview
This project focuses on Employee Data Analysis using Excel. It includes data cleaning, preprocessing, and building an interactive dashboard to analyze employee-related information such as departments, job roles, attrition, and performance trends.

🎯 Key Features
Data cleaning (handling missing values, duplicates, formatting)

Employee demographics (age, gender, department distribution)

Attrition & retention analysis

Salary & job role insights

Interactive dashboard with charts, slicers, and KPIs

🛠️ Tools & Techniques
Microsoft Excel for data cleaning and dashboard creation

Pivot Tables & Pivot Charts for analysis

Conditional Formatting for highlighting key trends

Slicers & Filters for interactivity
