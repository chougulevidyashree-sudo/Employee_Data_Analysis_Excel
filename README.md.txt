# Employee Data Analysis Dashboard

## Project Overview
This project is an Employee Data Analysis Dashboard developed using Microsoft Excel and Power BI. The dataset was cleaned and transformed in Excel, and an interactive dashboard was created in Power BI to analyze employee information and provide meaningful HR insights.

## Tools Used
- Microsoft Excel
- Power BI

## Project Tasks
- Cleaned the employee dataset by removing duplicates and handling missing values.
- Standardized and formatted the data.
- Built an interactive dashboard in Power BI.
- Used slicers and charts for easy data filtering and visualization.



## Skills Demonstrated
- Data Cleaning
- Data Analysis
- Microsoft Excel
- Power BI
- Data Visualization
- Dashboard Design
